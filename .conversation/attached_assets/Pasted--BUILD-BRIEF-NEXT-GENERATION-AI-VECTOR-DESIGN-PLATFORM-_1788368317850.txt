# BUILD BRIEF — NEXT-GENERATION AI VECTOR DESIGN PLATFORM

You are an elite team of product designers, UX designers, frontend engineers, graphics engineers, motion designers, AI engineers, and software architects working together to build a world-class creative application.

Build a **fully functional, web-based vector graphics editor** that is dramatically more modern, intuitive, visually stunning, and AI-powered than traditional vector editors such as Inkscape.

This is NOT a landing page.

This is NOT a mockup.

This is NOT a static dashboard.

Build the actual interactive application.

The product should feel like it was designed and engineered by a **$20 million world-class product team** and should be polished enough that a company like Adobe, Figma, or another major design-software company would immediately recognize the quality.

The visual benchmark is:

**Figma × Linear × Apple × Adobe × modern AI software**

but DO NOT simply copy their interfaces. Create an original visual identity.

# 2. IMPORTANT DEVELOPMENT RULE

Do NOT build a fake UI where buttons do nothing.

Every major interaction should actually work.

If a sophisticated feature cannot be fully implemented in the first version, build a clean working foundation and architecture for it rather than pretending it works.

Prioritize a functional MVP with excellent architecture.

The application should be structured so additional AI, vector, and embroidery functionality can be added later without rewriting the entire application.

---

# 3. TECHNOLOGY

Use a modern production-quality stack.

Preferred:

* React
* TypeScript
* Vite or an equivalent modern frontend build system
* Tailwind CSS or carefully structured CSS
* SVG as the initial vector rendering format
* Lucide or another high-quality icon system
* Framer Motion or an equivalent animation library
* Zustand or another lightweight state-management solution

Use a component-based architecture.

Keep code modular.

Separate:

* UI
* Canvas
* Vector engine
* AI functionality
* Export functionality
* Embroidery functionality
* Project management
* State management

Do not create one massive component.

# 41. IMPLEMENTATION INSTRUCTIONS

Start by building the actual working application.

Do not spend the entire task creating a marketing page.

Build the editor first.

Create the folder/component architecture before implementing complex features.

Make the core vector editor functional.

Then layer AI, embroidery, and advanced features on top.

After implementation:

1. Run the application.
2. Inspect every major screen.
3. Fix visual inconsistencies.
4. Fix broken interactions.
5. Remove placeholder-looking UI.
6. Improve animations.
7. Improve spacing.
8. Improve typography.
9. Improve responsiveness.
10. Ensure the application feels cohesive.

Iterate on the UI until it looks genuinely premium.

The final result should look like a **world-class professional creative application**, not a student project or a generated template.

Build it with the mindset that **the visual experience itself is one of the core features of the product.**
